# **App Name**: Vanguard Commerce

## Core Features:

- Rizwan AI Consultant Chat: An interactive AI chat tool trained on years of enterprise digital commerce data to provide strategic insights to potential recruiters or clients.
- Dynamic Experience Chronology: A scroll-triggered interactive timeline using GSAP and Framer Motion to visualize career growth at Systems Limited, OneClout, and Hashlogics.
- Enterprise Case Study Vault: High-fidelity project displays with role-specific breakdowns, architecture diagrams, and impact metrics like performance optimization and user scale.
- D365 & Tech Stack Matrix: A filterable skills dashboard highlighting expertise across Dynamics 365, Next.js, and complex payment integrations like Affirm and PayPal.
- Strategic Achievement Metrics: Data-driven counters and statistics displaying measurable successes, such as projects delivered and enterprise systems migrated.
- SEO & Persona Schema Optimization: Production-ready JSON-LD schema integration for high visibility in executive search and tech recruitment indexing.
- Seamless Consultation Lead Hub: An executive contact system with form validation and calendar availability visualization for high-priority outreach.

## Style Guidelines:

- Primary Color: Elegant Indigo-Purple (#8576ED) providing a sophisticated tech-leader vibe suitable for a Dark Mode interface.
- Background Color: Deep Carbon-Purple (#11101A) that ensures a modern, immersive 'executive suite' digital environment.
- Accent Color: Professional Corporate Blue (#5C8CF0) used for critical calls-to-action, signifying reliability and enterprise precision.
- A pairing of 'Space Grotesk' for authoritative headlines and 'Inter' for highly readable body text. 'Source Code Pro' is used specifically for technical blocks and code-driven sections.
- Utilization of thin-stroke Lucide icons with custom gradients to match the blue-purple primary palette, ensuring a clean SaaS aesthetic.
- A high-end 'Bento-style' grid system inspired by Vercel and Linear, emphasizing hierarchy, negative space, and modern alignment.
- Premium motion design including buttery-smooth parallax scrolling, magnetic button effects, and GSAP-orchestrated path-drawn timeline reveals.
